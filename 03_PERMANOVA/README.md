# PERMANOVA

Tests a multivariable Bray-Curtis model with `vegan::adonis2`; pseudo-F, R-squared, p-value, sample size, and permutation count are written by R. Zero-read communities are excluded. The null hypothesis is no association between composition and each predictor after the other terms. This tutorial uses **marginal** tests; sequential tests depend on formula order. Correlated environmental variables and spatial structure complicate individual-term interpretation.

Run `python 03_PERMANOVA/permanova.py`. The supplied metadata are site-level, so the script explicitly aggregates sequence libraries to site before matching. Use `permutation_block_column` only for a known repeated-sample block; blocks restrict exchangeable permutations but do not solve pseudoreplication or spatial confounding. The included data have no replicated categorical management variable, so dispersion testing is only activated after setting `categorical_predictor` to a valid column. Differences in dispersion can be mistaken for differences in centroids. Documentation: [vegan](https://vegandevs.github.io/vegan/reference/adonis.html).
