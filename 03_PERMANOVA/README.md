# PERMANOVA

Tests a multivariable Bray-Curtis model with `vegan::adonis2`; pseudo-F, R-squared, p-value, sample size, and permutation count are written by R. Zero-read communities are excluded. The null hypothesis is no association between composition and each predictor after the other terms. This tutorial uses **marginal** tests; sequential tests depend on formula order. Correlated environmental variables and spatial structure complicate individual-term interpretation.

Run `python 03_PERMANOVA/permanova.py`. The script sums raw reads to one community per field before matching field metadata, so its primary unit is 60 independent fields. Use `permutation_block_column` only for a known repeated-sample design; blocks do not solve pseudoreplication or spatial confounding. The synthetic dataset has replicated management categories; set `categorical_predictor = "management"` to add a dispersion check. Differences in dispersion can be mistaken for differences in centroids. Documentation: [vegan](https://vegandevs.github.io/vegan/reference/adonis.html).
