# Random Forest

`random_forest.py` uses a group-aware 80/20 split, 150 trees, and training-only imputation/encoding. R-squared compares predictions with a mean baseline, so it can be negative; RMSE and MAE are errors in response units. If the forest performs worse than the training-mean baseline, that is informative: these predictors do not support useful held-out prediction under this configuration. Importance is descriptive, not causal.

`leave_one_site_out.py` uses `LeaveOneGroupOut` and reports **pooled** metrics, never invalid individual-field R-squared values. It holds out both soil samples from each synthetic field together, so it tests prediction at unseen fields. Run both scripts with `python 07_Random_Forest/<script>.py`. Documentation: [scikit-learn](https://scikit-learn.org/stable/).

The included `n_estimators=500` and `min_samples_leaf=2` values are deliberately simple teaching defaults, not tuned settings. For a final analysis, choose candidate hyperparameters using cross-validation **only within the training data** (preferably repeated group-aware folds), then evaluate the chosen model once on a separate untouched test set. Report variation across several pre-specified random group splits or repeated cross-validation folds, rather than selecting the one split with the best result. Never use the held-out test sites to choose predictors, imputation settings, transformations, or hyperparameters.
